# City：朋友圈来源的会话漏斗（待预览验收，未上线）

## 现有能力与接入选择

本轮从生产 main（d7ac9bd）创建独立统计分支；代码中没有发现 Analytics SDK、统计脚本或事件接入。当前环境无法打开正式站 / Vercel 后台，不能确认项目级 Web Analytics 是否已启用，也不能查看已有历史数字。

优先复用当前 Vercel 项目的 Web Analytics 收集通道：不建数据库、不接第三方账号、不新增前台统计页面，不改玩法或表单。当前项目是否启用、当前套餐是否支持自定义事件、Preview 是否接收事件，需在后台核实。未启用或无事件能力时不能声称统计已可用；不要擅自升级付费套餐。

使用官方 `@vercel/analytics@2.0.1` 发布包所示的 window.va 队列 / 同源脚本 / beforeSend 接口（本项目为无构建静态应用，未添加运行时 npm 依赖）。统计脚本地址为 `/_vercel/insights/script.js`。

## 口径

| 节点 / 事件            | 何时计数                                                                      |
| ---------------------- | ----------------------------------------------------------------------------- |
| `city_home_session`    | 首页脚本完成初始画面显示                                                      |
| `city_content_session` | 逐站试玩任一站成功渲染；通常是点「开始走」后 A 第一站显示，而不是按钮点击瞬间 |

**“城市观察内容”暂按第一站成功显示定义，等待用户确认**。本站没有城市文章列表；真实地点记录页当前不额外触发内容事件。若用户指的是进入真实记录页，需要在验收前调整此口径。

会话定义：同一浏览器标签页、同源 sessionStorage，30 分钟无交互后重开一个会话；同标签页页面跳转、返回、刷新、重试、打开 A/B 多站均保留状态。记录 / 进阶页仅延长已有会话的活动时间，不增加事件。新的标签页通常是另一会话，浏览器通过 opener 复制的 sessionStorage 可能继承状态；这不是去重人数或跨设备访客数。

每个节点每会话最多排队发送一次；只有先计首页的会话才能计内容。来源以该会话首次计首页时的 UTM 为准：

- `utm_source=wechat_moments` → `source=wechat_moments`。
- 其他情况统一为 `source=other`，不把任意 query 字符串传给统计后台。

同会话后续去掉 UTM、站内导航或打开其他内容不会改写来源。新会话按新的入口重新判定。

## 数据最小化

自定义事件只有固定事件名和一个来源枚举，无 userId、sessionId、姓名、微信身份、GPS 坐标、地点名称、节点坐标、备注、理由或用户输入。去重标记和活动时间只留在 sessionStorage，不发送。

不主动发送默认 pageview；beforeSend 拒绝 pageview，事件 URL 统一清理为当前 origin 的 `/`，剥离 query、hash 和路径参数，脚本请求不携带 HTTP Referer。Vercel 仍会按服务本身处理必要请求 / 浏览器元数据；需核实其项目设置和隐私条款，不能将此代码描述为整个服务只存在两个字段。

存储不可用 / 损坏时不猜测会话，不发送事件，应用继续工作；拦截器、断网、禁用 JS 会造成漏记。排队发送不是服务端成功入库的证明，不进行重试风暴或指纹替代。

## 去哪里看数字

接通并确认真实入库后，打开 Vercel → 现有 `ember-city-observer` 项目 → Analytics / Web Analytics → Events（自定义事件）：

1. 使用同一时间范围，只看 Production 数据；不要混入 Preview 或本地测试。
2. 筛选自定义属性 `source = wechat_moments`，不要用 Referrer 代替。
3. 读取 `city_home_session` 与 `city_content_session` 的**事件总次数**，不是 Visitors / Unique Visitors 或页面 PV。
4. 内容打开率 = `city_content_session` 次数 ÷ `city_home_session` 次数 × 100%。首页为 0 时显示「暂无数据」。

代码按会话去重，因此这两个事件的总次数分别代表两个节点的可观测会话数。该方案没有发送会话 ID，不能做服务端跨设备去重或严格的跨日 cohort join；推广效果优先使用自发布 / 投放开始以来的同一累计窗口，跨时间窗口边界的转化需谨慎解读。
